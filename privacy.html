Política de Privacidad - CubitoMusic

Última actualización: 19 de septiembre de 2026

1. Información que Recopilamos

  • Datos de Discord: ID de usuario, nombre de usuario y ID del servidor.
  • Datos de Uso: Comandos utilizados, horarios de uso y canciones reproducidas (sin información personal identificable).
  • Datos de Voz: El Bot se conecta a canales de voz solo cuando lo solicitas explícitamente. No se graba ni almacena audio. La conexión termina al salir o usar /stop.

2. Cómo Usamos tu Información

Utilizamos los datos recopilados para proporcionar el servicio de música, mejorar la funcionalidad, diagnosticar problemas y prevenir el uso malicioso del bot.

3. Almacenamiento, Seguridad y Compartir Datos

Los datos se almacenan en servidores seguros. No almacenamos conversaciones ni audios. No vendemos ni compartimos tus datos personales con terceros, excepto por requisitos legales, seguridad o proveedores de infraestructura bajo confidencialidad.

4. Retención y Tus Derechos

Los datos de uso se eliminan tras 90 días de inactividad. Tienes derecho a acceder, rectificar, solicitar eliminación u oponerte al procesamiento de tus datos contactando al soporte.
